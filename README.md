# Talking Travel — вёрстка макета

Учебный проект по вёрстке. Две страницы макета «Talking Travel»
на HTML и CSS. Без фреймворков и без JavaScript.

- **Макет:** https://www.figma.com/design/xC3VHAMZNq9Nm9x2TgnHei/Locofy-Sample-Project---Talking-Travel--Community-

## Что сделано

- **index.html** — главная страница.
- **story.html** — страница статьи про Швейцарию.
- **css/style.css** — все стили для обеих страниц.

## Структура проекта
```
web1/
  index.html          главная страница
  story.html          страница статьи
  blog.html           черновик (пустой)
  css/
    style.css         все стили
  img/                все картинки
  docs/
    decomposition.md  разбор макета и оценка времени
    tokens.md         цвета, шрифты, отступы
  README.md
  .gitignore
```

## Что решила сама (чего не было в макете)

- **Кнопки и ссылки** — при наведении меняют цвета
  (в макете этого не видно, но так удобнее).
- **Переходы между страницами** — «Home» и «Story» в меню работают.
  «Gallery» и «Contact Us» пока ведут в никуда — страниц для них нет.
- **Длинный текст** — не ломает вёрстку, переносится на новую строку.

## Что проверяла

- Навигация с клавиатуры — все ссылки и кнопки доступны.
- Альтернативный текст — есть у всех картинок.
- Контрольные ширины — 360, 768, 1280.
- Горизонтальной прокрутки на 360 px нет.
