Задание 1.

3. Главная страница

    2) Первый экран - лозунг, пояснение, две кнопки и фото на фоне
    3) Второй экран - слева фото, справа текстовый блок с кнопкой

иконки в шапке - одинаковый цвет и размер

    1) Шапка - `<header>`
        Кнопки - `<button>`
        Ссылка (переход) - `<a>`
        Список - `<ul> + <li> `
    2) Первый экран - `<section>`
        Заголовок - `<h1>`
        Пояснение - `<p>`
        Кнопки - `<button>` + Ссылка (переход) - `<a>`
        Изображение - `<img>`
    3) Второй экран -  `<section>`
        Заголовок - `<h2>`
        Пояснение - `<p>`
        Кнопки - `<button>` + Ссылка (переход) - `<a>`
        Изображение - `<img>`
